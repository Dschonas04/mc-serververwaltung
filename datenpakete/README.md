# Datenpakete

Liegen auf dem Server unter `world/datapacks/`. Nach einer Änderung `/reload`.

| Paket | Zweck |
|---|---|
| `tafel` | Seitenleiste „Tode – Top 7“ über die Teams `platz1`..`platz7` (Präfix Platz, Zusatz Todeszahl), alle 100 Ticks neu |
| `spawnschutz` | Schutz rund um den Spawn |
| `dimensionssperre` | Sperrt das Ende (Spieler werden zum Spawn zurückgesetzt); der Nether ist offen |
| `bauhoehe` | Bauhöhen-Regeln |
| `meissel` | Meißel-Anpassungen |
| `limbo-modsachen` | Limbo-Verzauberungen auch auf Aerial-Hell- und Mod-Ausrüstung, dazu einmalige Umbaufunktionen der Limbo-Gegend |
